# AWS Cross-Account Transit Gateway Lab using Terraform

> Production-style Terraform project demonstrating AWS Transit Gateway (TGW) connectivity between multiple AWS accounts using reusable Terraform modules.

## 🚀 Features

- AWS Transit Gateway
- Cross Account Networking
- AWS RAM Sharing
- Terraform Modules
- Remote State
- Bootstrap Infrastructure
- VPC Endpoints
- EC2
- IAM Instance Profiles

## 🛡️ Security

This repository does NOT include:

- terraform.tfstate
- .terraform/
- terraform.tfvars
- AWS credentials

Use AWS CLI profiles or IAM roles for authentication.
